Scrap salvage parts

What "Fill scrap" tries to recover from the offcut, biggest first. Crates are cut from the same 19mm melamine, so these come off the sheet you are already cutting — and every job can place any crate size: this is using up leftover, not a parts list for the job on the bench. Qty is how many you want in total across this nest, not per sheet; set one to 0 to leave it out.

🔗 rows come from the real crate product, so they are cut with their grooves. A row with no link is only cut to size — the panel comes off blank.

Derive this layout from another product

Takes a layout that already works and drops this product's parts into it, each one centred on its counterpart. Sheets, layers and positions stay put, so the table looks the same to whoever is stacking it — only the parts are smaller.
It only works one way: every part here has to be the same size or smaller than the part it replaces. Anything that is not is named below and nothing is applied.

Which parts are trim or doors?

Ticked parts go to the top layer and land on the last sheets, so the robot stacks everything underneath and a person places these by hand.
Suggestions come from a Ø35 hinge cup, or a name reading door / trim / valance / toe / fascia. Both guess wrong sometimes — a hinged top carries the same cups a door does — so nothing is applied until you tick it.

Which parts run across the grain?

On a grained board the grain runs along the sheet's length, so every part has one way up. Normally that is the part's long side along the grain. Tick a part here to say the opposite: its short side along the grain, on purpose.

This list belongs to this product. The four ticked by default (1A, 1B, 1C, 8A) are the Boaz beds' — the same codes mean different parts in other products, so check them before trusting them. A part that cannot physically go across the grain on this board is marked below.

Sheet materials

One row per sheet you actually buy. Sheet size lives with the texture, not the material — your white is 1550×2770 while black and monaco are 5×8, so they are separate rows. Name / Abbr / Material ID / Texture ID must match Mozaik, or the optimizer will not bind the nest to the right stock.
